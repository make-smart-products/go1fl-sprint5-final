# Модуль фитнес-трекера

## Тестирование проекта

Рядом с файлами, которые вы будете редактировать, находятся файлы с суффиксом _test.go. В них содержатся юнит-тесты, проверяющие корректность вашей реализации. Эти тесты автоматически запускаются на GitHub. Чтобы работа была зачтена, ваш код должен успешно проходить все тесты. Обратите внимание: изменять содержимое тестов запрещено.

Вы можете запускать тесты локально, выполнив следующие команды в корневой директории репозитория:

```bash
go mod tidy
go test -v ./...
```

## Новостной сайт

В репозитории также есть отдельное веб-приложение с новостной лентой из проверенных российских RSS-источников: РИА Новости, ТАСС, Интерфакс и Коммерсантъ. Сервер кеширует материалы и обновляет их каждый час.

Запуск:

```bash
go run ./cmd/news-site
```

После запуска сайт будет доступен по адресу [http://localhost:8080](http://localhost:8080).

Полезные параметры:

```bash
go run ./cmd/news-site -addr :9000 -refresh 1h
```

JSON API текущей ленты доступен по пути `/api/news`, проверка состояния сервера — по `/healthz`.
