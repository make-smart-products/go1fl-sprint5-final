# Новостной сайт

Современный новостной сайт на Go, который собирает материалы из проверенных российских RSS-источников и обновляет ленту каждый час.

## Источники

- РИА Новости
- ТАСС
- Интерфакс
- Коммерсантъ

## Возможности

- почасовое обновление RSS-лент на сервере;
- кеш последней успешной подборки;
- удаление дублей по ссылкам;
- адаптивная главная страница с карточками новостей;
- поиск по заголовкам, источникам и описаниям;
- фильтр по категориям;
- JSON API `/api/news`;
- endpoint состояния `/healthz`.

## Запуск

Из корня проекта выполните:

```bash
go run ./cmd/news-site
```

Откройте сайт в браузере:

```text
http://localhost:8080
```

Можно указать другой порт и интервал обновления:

```bash
go run ./cmd/news-site -addr :9000 -refresh 1h
```

Тогда сайт будет доступен по адресу:

```text
http://localhost:9000
```
